# nacarbarkat

تطبيق React تم إنشاؤه بواسطة AI Builder.

## 🚀 البدء السريع

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء للإنتاج
npm run build
```

## 📁 هيكل المشروع

```
nacarbarkat/
├── public/
│   └── index.html
├── src/
│   ├── components/    # مكونات قابلة لإعادة الاستخدام
│   ├── pages/         # صفحات التطبيق
│   ├── context/       # Context API
│   ├── hooks/         # Hooks مخصصة
│   ├── services/      # خدمات API
│   ├── utils/         # وظائف مساعدة
│   ├── styles/        # ملفات CSS
│   └── router/        # إعدادات التوجيه
├── package.json
└── vite.config.js
```
